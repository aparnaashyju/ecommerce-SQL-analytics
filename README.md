💡 Key Business Questions

Some of the questions answered in this project include:

Which product category has sold the most units?
Who are the top 5 customers by total spending?
Which shopping malls generated more than ₹10,000 in revenue?
Which customer has spent the highest total amount?
Which customers are repeat customers?
